# 家庭记账理财设计

采用用户确认的托管方案：Vue 3 / TypeScript 前端部署 GitHub Pages；Supabase Auth、Postgres、Realtime 和 Edge Functions 承担后端，无需购买维护云服务器。没有凭据时使用显式标注的本机演示数据，不声称已联网或开启自动账单同步。

## 页面与交互

1. 总览：家庭净资产、期间收入支出、资产趋势、成员资产卡、最近交易、快捷记账。
2. 账本：自然语言或语音转文字、编辑确认入账、按日期和成员筛选、搜索、CSV 导入预览与去重、删除本人确认的错误交易。
3. 资产：成员和类型配比、账户管理、估值快照录入。贷款以正数记录，在净资产中扣除。
4. 收益：周/月/季/年/自定义日期；投资账户期初与期末、外部资金流、估值收益、Modified Dietz 非年化收益率。未录入开始日前一天和截止日的投资估值，或缺少正的计息基数时不输出伪造收益率。
5. 连接：邮箱验证码登录、创建家庭/加入家庭邀请码、实时共享；AI 配置状态、账单接口、完整 JSON 备份导出和恢复。

## 数据与安全边界

金额以分整数存储，展示人民币。家庭成员（资产归属人）与登录用户分开。家庭成员均可管理共享账本；邀请仅家庭创建者生成，邀请有有效期且一次使用。RLS 根据 auth.uid() 与家庭 membership 限制所有业务表。公开前端仅存 Supabase 公共 publishable/anon key，不存 service role 或模型密钥。演示数据与云端账本隔离，切换不自动上传演示数据。

自动导入先实现统一已授权账单接收协议与持久化幂等键，来源端保存提供方密钥并调用 Edge Function。家庭管理员创建渠道，渠道绑定家庭、允许的账户及默认成员，密钥哈希保存在服务端。Webhook 验证密钥与绑定范围、限量校验金额、日期和源交易号；数据库唯一约束去重；Realtime 更新网页。银行卡/微信/支付宝没有已授权通用接口时，通过官方导出 CSV 导入，不伪造连接状态。浏览器无法直接读短信。邮件服务由用户通过提供方转发/解析后接入统一协议；不存邮箱密码。

## 收益口径

估值快照表示当日结束的账户价值。某日余额为最近一条快照加快照之后的净资金流。筛选区间包含开始和结束日，期初使用开始日前一日。内部转账在全家组合中相抵，在某个成员的组合中作为出入金。投资账户估值收益为期末价值减期初价值减净外部流入；投资收益类收入计入投资收益。资产配置按正资产计算，负债另列。

## 验证

Vitest 验证解析、日期、CSV、去重、备份结构、家庭转账及收益算法；Playwright 验证记账确认和持久化、筛选、账单预览、手机布局；ESLint、vue-tsc、生产构建验证。Supabase SQL 和 Edge Functions 提供部署及联调指南，真实服务验证需要项目配置后执行。
